# دليل الأدوية الأردني | Jordanian Medicine Directory

> **Made by osamaabualia**

دليل صيدلاني وطبي متكامل وشامل للأدوية المتوفرة في المملكة الأردنية الهاشمية والأدوية الشائعة بدون وصفة طبية (OTC). يهدف الدليل لتوفير مرجع علمي وتثقيفي دقيق للمرضى والكوادر الطبية.

---

## المميزات الرئيسية | Features

- 💊 **أكثر من 1,000 دواء**: تغطية شاملة للأدوية التجارية والعلمية المتوفرة في الصيدليات الأردنية.
- 📦 **عبوات دوائية رقمية**: تصميم بطاقات عبوة دوائية أنيقة تُظهر اسم الدواء بوضوح بالعربية والإنجليزية والعيار والمُصنّع دون الحاجة لتحميل صور خارجية.
- 🗣️ **نطق صوتي إنجليزي دقيق**: نطق أسماء الأدوية والمصطلحات الإنجليزية عبر محرك النطق المدمج.
- ⚖️ **مقارنة دوائية جنباً إلى جنب**: مقارنة فورية بين دواءين مع تنبيهات تفاعلية ذكية (مثل التحذير من تكرار الباراسيتامول).
- 🧮 **حاسبة الجرعات الآمنة**: حساب الجرعات للأطفال والبالغين حسب الوزن والعيار، وتنبيه بالحد الأقصى اليومي.
- 📱 **رمز استجابة سريعة (QR Code)**: لمشاركة بطاقة الدواء فوراً عبر الهاتف.
- 🖨️ **طباعة نشرة دوائية A4**: تنسيق جاهز للطباعة الصيدلانية لمساعدة المرضى وكبار السن.
- 🌐 **ثنائي اللغة بالكامل**: دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).

## التشغيل والتطوير المحلي | Getting Started

### المتطلبات
- Node.js (v18+)
- npm أو yarn أو pnpm

### خطوات التثبيت والتشغيل

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```
